# Muse Bookstore
Muse Bookstore project, a web-based platform designed 
to foster a community of book lovers, facilitate book exchanges (swapping and selling), and 
encourage creative writing. The platform aims to address the fragmented landscape of existing 
book-sharing solutions by offering a comprehensive and user-friendly experience that combines 
the best features of online reading platforms and physical book exchange services.

Users of the system are,
1. Unregistered Users  
These individuals can browse available books, explore community features, and learn 
about the platform. They have limited interaction but represent potential future members.

2. Registered Users (Book Owners)  
These are the core users of the platform. They can list their books, request books from 
others, participate in community forums and writing groups, manage their profiles, 
purchase tokens, and engage in book sales or swaps.

3. Registered Users (Book Borrowers/Buyers)  
This subset of registered users focuses on acquiring books. They can search for books, 
request exchanges, manage their borrowing history, participate in discussions, and join 
communities.

4. Child Users 
Child users can explore books, search, buying- parent acc get buying request, read child 
friendly articles, write creative articles, give reviews to books in child category 
  
5. Community Ambassadors   
These volunteers play a vital role in promoting the platform within their local communities. 
They facilitate book exchanges, moderate community content, organize events, and 
provide user support.

6. Community Admins  
Manage communities, oversee community ambassadors, approve community creation 
requests, handle community-related issues and generate reports.

7. Transaction Admins  
Responsible for financial aspects, including managing payments, processing token 
purchases, handling book sale transactions, and generating financial reports.

8. Super Admins  
Oversee the entire platform, manage user accounts, monitor system performance, handle 
escalated issues, create admin accounts, and have access to all system data and 
functionalities.

## Technologies used
Frontend- HTML, CSS, JS
Backend- PHP
Database- MySQL
